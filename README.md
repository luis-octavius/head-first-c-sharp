# Head First C# 

Esse repositório contém todos os exercícios que devem ser feitos no Visual Studio, a partir do livro [Use a Cabeça C#](https://www.amazon.com.br/Use-Cabe%C3%A7a-Guia-Aprendiz-Programa%C3%A7%C3%A3o/dp/6555205962/ref=asc_df_6555205962?mcid=7f5fa21e5dc43dfab6b6042568379446&tag=googleshopp00-20&hvpos=&hvpone=&hvptwo=&hvqmt=&hvdvcmdl=&hvlocint=&hvocijid=10169767577683163835-6555205962-&hvexpln=0&language=pt_BR).

## Exercícios
- [Guy](./Guy): Aplicação com classe Guy para apresentação de orientação a objetos.
- [ExperimentWithControls](./ExperimentWithControls): Treinamento do uso de controles em aplicações que utilizam WPF.
- [MyFirstConsoleApp](./MyFirstConsoleApp): Primeira aplicação de console em C#.
- [Simple API](./[Simple%20API): API de produtos com CRUD completo utilizando ASP.Net Core.
- [PickRandomCards](./PickRandomCards): Aplicação que randomiza a escolha de cartas de baralho.
- [PickACardUI](./PickACardUI): Interface visual de PickRandomCards.
